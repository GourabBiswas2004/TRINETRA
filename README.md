# 🚨 TRINETRA – AI-Assisted Intelligent Safety and Emergency Response System

**TRINETRA** is an AI-powered intelligent safety system designed to automatically detect potential emergencies and initiate emergency response alerts.

It combines Artificial Intelligence, Machine Learning, IoT, and Cybersecurity to identify possible distress situations using smartphone motion sensors, audio signals, and contextual information.

Unlike traditional safety applications that rely entirely on manual SOS activation, TRINETRA aims to detect emergencies automatically, assess risk levels, and securely communicate alerts even in limited network conditions.

### ✨ Key Features
- AI-based fall and abnormal motion detection.
- Audio-based distress sound recognition.
- Intelligent multimodal risk assessment.
- Automatic emergency alert generation.
- Secure evidence encryption using AES-256-GCM.
- Emergency communication through TLS, SMS, BLE, and LoRa.

### 🛠️ Technologies
